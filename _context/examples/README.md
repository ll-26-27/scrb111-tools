# _context/examples

Four past final-project transcripts and the follow-up questions the professor wrote for each, with the students' names removed. Claude reads all of it, whole, before writing questions: a transcript beside the questions the professor actually asked about it is the best evidence of how she asks.

- `04_transcript_protacs_anonymized.md`: sample 1, PROTACs
- `05_transcript_tooth_regeneration_anonymized.md`: sample 2, tooth regeneration
- `06_transcript_epigenetic_gene_silencing_anonymized.md`: sample 3, epigenetic gene silencing
- `07_transcript_ipscs_organoids_anonymized.md`: sample 4, iPSCs and organoids
- `08_professor_original_followup_questions_anonymized.md`: the professor's own questions for the four

## Notes on the materials

- Names are replaced with [Student A] and [Student B] in the titles and wherever they occur in the speech; each file's opening note says how many places. Nothing else is changed.
- The transcripts keep speech-to-text mistakes and awkward wording exactly as recorded (for example "Protax" for PROTAC and "animal" for enamel).
- The professor's questions are in their own file, so they can be left out when testing a guide blind and compared afterwards.
- To add a year: one transcript file per video and the questions asked, names removed. Versions with names belong in `_context/private/`.
